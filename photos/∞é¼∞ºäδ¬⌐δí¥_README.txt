FindIt 실제 사진 넣는 방법
==========================

1. 이 photos 폴더에 사진을 아래 "파일 이름"으로 저장 (jpg / png / webp 모두 가능)
   예) A.jpg, B.jpg, 07.png
2. 앱 창을 닫고 "데모데이터_초기화.bat" 실행 (Y)
3. "FindIt_실행.bat" 실행 → 그림 대신 실제 사진이 보임
   (사진이 없는 번호는 지금처럼 그림으로 나옴)

사진 구하는 법
--------------
- 가장 좋음: 집에 있는 비슷한 물건을 Jaden이 직접 촬영
  (진짜 앱처럼 보이고, 저작권 걱정 없음, 밝은 곳에서 단색 배경)
- 무료 사진 사이트: pexels.com, unsplash.com (무료 사용 가능 라이선스)
  → 실제 CAC 출품 시에는 사진 출처도 함께 밝히기
- 가로 사진 권장 (앱 카드가 가로형)
